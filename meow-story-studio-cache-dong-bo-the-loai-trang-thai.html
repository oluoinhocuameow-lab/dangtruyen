01. 📚 Chọn hoặc tạo truyện
02. 🌷 Thông tin truyện
💗 Tự đặt code truyện khi tạo mới.
Ví dụ: meow001, truyen001, mat-the-01.
Code này được dùng làm ID truyện trên Firebase.
Không thể sửa code sau khi tạo truyện.
🖼️ Không giới hạn dung lượng ảnh ở giao diện. Ảnh lớn vẫn phụ thuộc giới hạn Firebase.
03. ✍️ Soạn chương
📜 Khung soạn có thanh cuộn riêng.
🖼️ Ảnh được chèn trực tiếp vào nội dung chương.
Không giới hạn dung lượng ảnh ở giao diện, nhưng vẫn phụ thuộc giới hạn Firebase.
04. 🐾 Trạng thái đồng bộ
Chưa kết nối.
Firebase Realtime Database · Cache bật ⚡ · Thể loại + trạng thái đồng bộ

Dữ liệu truyện: stories/{storyId}/info
Dữ liệu chương: stories/{storyId}/chapters/{chapterId}
Thể loại dùng chung với Đăng truyện: settings/tags
Trạng thái dùng chung với Đăng truyện: info.status (Đang ra / Hoàn thành / Drop)
ID chương số là ID được dùng để hiển thị số chương.
